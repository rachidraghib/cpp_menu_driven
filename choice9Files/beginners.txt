Q. What is the ASCII table ?

The ASCII (American Standard Code for Information Interchage) table is a standard character
encoding scheme that defines the correspondence between characters and numerical values 
in the range from 0 to 127.Each character in the ASCII table has corresponding numerical 
value representing it as byte.

This table standardizes the representation of text in the computer and enables data exchange.

Q. What is the Preprocessor ?

The preprocessor in C++ is a component of the compiler that performs preliminary processing
of source code before its actual compilation. it executes various tasks such as defining 
symbolic constants using #define directives,excluding parts of the code using #ifdef,#endif
derictives,and more.

The preprocessor helps to make the code more scructured,extends its functionality, and 
provides greater flexibility in managing the software project.

Q. what are header files in C++ ? /***************

Header files in C++ contain declarations of functions,classes,variables,etc, intended for 
reuse across multiple source files.
They are included at the beginning of source files using #include. header files promote 
modularity,code reuse and organizatiion in large prijects by seperating interface

Q. How does #include work in C++ ? 

The #include directive is used to include the contents of another file in the current source 
file.When encountered,the preprocessor replaces #include line with the contents of the 
specified file before compilation begins.

Q. How to protect a header file from being included multiple times in C++ ? /********

C++ protects a header from being used multiple times by including guards or #pragma once.
Include guards involves defining a unique identifier within the header file and using 
conditional preprocessor directives to include the content that hasn't been defined.

Q. what's a compiler in C++ ?

A compiler is a software tool that translates source code into machine code or executable 
code that a computer understands and executes. It performs various tasks such as lexical 
analysis,syntax analysis,optimization and code gereration.

The compiler ensures that the source code adheres to syntax and the rules of the programming
language and produces efficient and executable output. 

KEY TASKS WHEN COMPILING

    1.Translations: 
    converts source code to machine code.

    2.Syntax and semantic analysis:
    scans the code for errors ensuring it follows language rules and validates types.

    3.Optimization:
    rearrages or refines the code to improve effeciency and make programs faster and more compact.

    4.Error reporting:
    identifies errors in the code before deployment

    5.Code generation:
    produces an executable file 

Creat Source File
    ---> Run preprocessor to convert source file directives to source code statements
    ---> Run compiler to convert source program into machine binary code. 
    ---> Run Linker to connect hardware specific code to machine instructions producing 
         an executable file.

Q. what's a linker in C++ ?

A linker is a software utility responsible for combining multiple object files generated
by the compiler into a single executable program or library.
It resolves references between diffirent modules or object files,ensuring that functions
and variables defined in one file that can be accessed and utilized by other parts of 
the program.
The linker also handles the inclusion of libraries and external dependecies,allowing for 
the creation of standalone executables or shared libraries that can be executed and utilized
by other programs.

Q. what's the difference between while loop and do-while loop in C++ ?

The diffirence is that while loops are entry-controlled loops, where the condition is checked
before entering the loop body.
In contrast, do-while loops are exit-controlled loops,where the condition is ckecked after
executing the loop body, ensuring that the body is executed at least once.

Q. What's a pointer in C++ ?

***A pointer in C++ is a variable that stores the memory address of another variable rather
than storing a direct value.
Instead of holding data like an interger or a string,it holds numeric address that points to
where data lives in the system memory.

*****BASIC SYNTAX AND OPERARIONS*****

Working with raw pointers requires understanding two primary operators:
--->The address of operator(&). It retrieves the memory address of an existing variable
--->The dereference operator (*). This operator accesses or modifies the value stored in the 
memory address the pointer holds.

 *****PRIMARY USE OF POINTERS*****
 
1.Dynamic Memory Allocation
Pointers allow you to allocate memory on the during runtime using the (new) operator.this is 
essential when the size of data (like an array) is unknownat compile time.

2.Building Dynamic Data Structures
Complex and sizable data structrures depends on pointers to link data segments together 
in memory.

Linked list: Every node contains a pointer to the next node.
Trees and Graphs: Nodes use pointers to reference their child or neighbor nodes.

3.Effecient Data Passing(pass-by-pointer)
Passing large structures or objects to a function by value duplicates the data,which wastes
memory and processing time.Passing a pointer copies only fixed size nenory addrees (typically
4 or 8 bytes),while granting the function direct access to modify the original variable.

4.Runtime Polymorphism(Object-oriented Programming)
Pointers are required to achieve subtype polymorphism in C++. A base class pointer can pointer
to a derived class object,allowing the program to call overriden virtual methods at runtime.

Q. what's a function  in  C++ ?

A function is a named block of code that performs a specific task. Functions are reusable 
and modular,allowing you to break down complex tasks into smaller,more manageable parts.
They typically accepts parameters,performs some operations and optionally return a result.
 

***Function Pointer as Arguments (Callbacks) One of the most useful applications of function 
pointers is passing functions as arguments to other functions.
This allows you to specify which function to call at runtime.

#include <iostream>

    return a + b;
}

}

  	calc(10, 5, subtract);
